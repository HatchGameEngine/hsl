# hsl

The compiler and VM (Virtual Machine) for the Hatch Scripting Language, as well as the `hsl` and `hslc` programs, and the `libhsl` library.

The code may not be up-to-date with the implementation in Hatch. Currently, this can only be built with the provided `CMakeLists.txt`.

`libhsl` is currently a proof of concept, and the API is subject to change.
